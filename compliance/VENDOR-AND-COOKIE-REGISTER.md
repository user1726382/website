## Approval checks
Verify contract entity, service, subprocessor list, hosting region, data transfers, appropriate GDPR Art. 28 agreement, SCCs/adequacy and transfer risk if needed, retention/deletion, incident notification, access controls, encryption, backups, and right to audit.

## Cookie/storage inventory
Current static source: no intentional optional cookies, tracking pixels or analytics. Verify actual hosting behavior and future integrations. Do not install a cookie banner by default; obtain consent for nonessential access/storage where required and provide a withdrawal mechanism.

## Hosting decision
Public GitHub Pages is a preview, not an approved production host for the commercial business. Review provider acceptable-use terms and select appropriate production hosting before launch. Candidate files must not be stored in public repository or static site.
